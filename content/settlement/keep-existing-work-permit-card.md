If the notification letter says to continue using the existing card, the worker must keep that card. Returning it when it is not needed costs $65.40, including GST, to replace the pass.

<!-- source-excerpt -->

> After the Work Permit is renewed, print and check the notification letter to see:
> If notification letter states
> The existing card
> 
> Continue using the existing card.
> 
> Must be kept by the worker.
> Note: If you return it when you don’t need to, you have to pay $65.40 (including GST) to replace the pass .
